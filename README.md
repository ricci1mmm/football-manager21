# Football Manager 21 - game-v2

Полная переработка игры с нуля.

Цель: браузерный футбольный менеджер с 2D матчами.

## Архитектура
- engine/ — игровой движок матча
- manager/ — логика клуба и сезона
- ui/ — интерфейс
- data/ — команды и игроки

## Первый этап
- 2D поле
- симуляция матча
- игроки, мяч и события
